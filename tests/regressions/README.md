# Retained Regression Corpus

This directory contains deterministic regression fixtures and failure reproduction artifacts for `dupe`.

## Directory structure

- `fixtures/`: deterministic regression cases preserved in CI.
- `failures/`: preserved failure reports generated by differential testing when a mismatch occurs.

## Regression fixture format

Each fixture file in `fixtures/*.json` defines:
- `name`: unique identifier for the regression case.
- `description`: rationale or defect description.
- `seed`: optional generation seed if derived from the fuzzer.
- `manifest`: map of relative POSIX paths to hex-encoded file content.

## Running regression tests

The regression suite runs automatically during:
```bash
python3 tests/phase4_differential.py
```

To reproduce a specific failure artifact:
```bash
python3 tests/phase4_differential.py --reproduce <path-to-failure.json>
```
